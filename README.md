# 知答 培训客服知识库

客服入口 `/`：登录、记忆平台、粘贴问题、匹配已审核答案、编辑复制、登记未解决问题。

管理入口 `/admin/login`：管理员登录，知识新增编辑、Word 文字预览及草稿导入、审核发布、客服及管理员账号维护、问题处理和 JSON 导出备份。

## 部署

Vue + Vite，Vercel Node Functions，Neon PostgreSQL。生产配置：`DATABASE_URL`（或 `POSTGRES_URL`）、`ADMIN_USERNAME`、`ADMIN_PASSWORD`、至少 32 位 `JWT_SECRET`。无默认密码。环境管理员可创建其他管理员与客服账号；该初始账号在 Vercel 环境变量中维护。数据库首次访问时创建独立的 support 表，旧作品集数据表保留。

`npm ci`、`npm run build`。测试：`node --test tests/support.test.js`。前端开发 `npm run dev`；完整后端本地开发使用 `vercel dev` 并配置开发环境变量。

## 使用

1. 管理员在知识管理中新增问答，或选择 Word 导入。
2. .docx 文件不超过 10 MB。仅提取正文文字，图片不识别，表格结构和自动编号可能丢失。旧 .doc 请另存为 .docx。
3. “问题：/答案：”结构可按规则拆分；普通手册需人工整理。核对后保存草稿，再编辑审核发布。
4. 客服通过账号登录根路径；平台选填，未选平台也可提交并记录到待处理列表，管理员确认平台后处理入库。选定平台时仅检索该平台的已发布条目；可配置 AI 整理回复，具体见 AI配置说明.md。多条匹配要求人工选择，资料不足时等待人工处理。
5. 管理员定期导出 JSON 备份；完整数据库恢复依赖 Neon 备份。备份文件包含内部资料，请按部门规定保管。

HTTP-only Cookie 会话有效期 8 小时；修改密码、角色或停用会撤销该账号已有会话。没有公众注册入口。原作品集接口已停用。

账号管理提供“修改我的密码”和逐行“重置密码”。本人修改需验证当前密码，管理员重置其他账号保留其角色及启停状态。超管首次改密后以数据库密码为准，环境中的 ADMIN_PASSWORD 不再用于该账号登录；修改环境变量不能覆盖已保存的新密码。忘记数据库中的超管密码时需由部署及数据库负责人走人工恢复流程，本版本没有公开的免验证找回入口。

客服端只选择平台；每次点击生成回复先记录问题，保存失败时停止生成并提示。管理员填写最终回复后处理成功，单条数据库语句同时发布知识与更新问题状态；同一问题再次处理更新其关联知识。平台列表暂来自已发布知识，待提供正式平台清单后维护。

## 问题图片附件

客服问题支持选择或粘贴 JPG、PNG、WebP 图片，最多 3 张、每张原图 10 MB。浏览器移除原图元信息并压缩为最长边不超过 1600 像素、每张不超过 300 KB 的 JPEG。可以只传图片，平台仍选填。图片随问题在同一 SQL 语句中保存至独立附件表；列表只返回附件编号和名称，查看图片需有效登录且为问题提交人或管理员，响应不缓存。

配置 AI 后，截图发送至 OpenAI Responses API 提取页面状态及报错信息，然后检索所选平台知识并生成回复；识别结果在客服端与后台显示并标记待核对。未选平台时仍识图并记录，不跨平台推断答案。未配置 AI、识别失败或资料不足时转人工。管理员在待处理列表查看原问题附件，补充具体问题描述、平台及最终回复后发布文字知识。附件保留在原问题中，不自动复制到知识库。现有 JSON 导出包含附件索引而非图片内容，完整恢复需数据库备份。复用 OPENAI_API_KEY；可选 OPENAI_VISION_MODEL 单独指定识图模型，默认使用 OPENAI_MODEL 或 gpt-4.1-mini。原有数据库账号需有建表权限。
